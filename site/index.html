three-gift-effects

一组「粒子从起点飞出来、聚成一个能认出来的形态」的演出型特效。 挂到任意 Three.js 场景就能用 —— 你只注入锚点，其余全交给库。 不需要重建场景、不需要美术资产、不需要动 shader。

A drop-in particle VFX library for Three.js. You supply the anchors; it supplies the show.

Design Principle

唯一的场景耦合点，是一个锚点对象

库不自己去 root.getObjectByName(...) —— 不同工程的命名千奇百怪，硬找必然静默失配。 所有定位量由宿主算好、运行时注入；偏移量、粒子预算、GLSL 全部由库自己持有。

字段类型说明
stageBox3表演区包围盒。只要 max.y（台面高度）和水平范围是对的即可
micVector3表演点。礼物终点、安全区都以它为基准推算
seatsArray<{eye}>观众席视点。库会挑一个最靠镜头的当「送礼人」
layoutobject可选，覆盖 GIFT_LAYOUT 里的任意偏移量

Quick Start

四步挂上去

import * as THREE from 'three';
import { createGiftEffects } from 'three-gift-effects';

const gifts = createGiftEffects(scene, { coarse: false, reduced: false });

// 1) 告诉它你的舞台在哪（唯一的场景耦合点）
gifts.setAnchors({
  stage: new THREE.Box3().setFromObject(stageMesh),
  mic:   new THREE.Vector3(1.0, 1.8, 0),
  seats: seats.map((s) => ({ eye: s.eye.clone() })),
});

// 2) 播放
gifts.trigger('giftDeer');   // 或 'giftPath'

// 3) 每帧更新（传相机与画布像素高，用来换算 px/米）
function frame(dt) {
  gifts.update(dt, camera, renderer.domElement.height);
  renderer.render(scene, camera);
}

// 4) 卸载
gifts.dispose();
three 是 peer dependency（≥0.160.0）。库不替你安装、也不打包 three —— 你的工程用哪个版本，它就用哪个版本。 本仓库是源码分发，直接拷 src/ 或走 submodule 即可。

Why it's pluggable

四条硬约束

零写死坐标

demo 里拖动「移动舞台」会整体平移并重新注入锚点，效果照旧正确 —— 代码里没有任何绝对世界坐标。

颜色全走 key

色板通过 GIFT_SKIN 的 key 暴露，applySkin() 实时覆盖，不需要改 GLSL。写错 key 会被忽略而不是静默失效。

三档粒子预算

high / mid / low 覆盖高中低配；初始档位由 coarse / reduced 决定，运行时还能 degrade() 逐级降。

可定格验收

seek(kind, seconds) 能停在任意时刻 —— 自动化验收可以逐帧截图，而不是只看首帧。

深度是红线

全部材质 depthTest:true + depthWrite:false，粒子被人物与家具正确遮挡；并对「面部 + 麦克风」安全区主动降亮。

可继续扩效果

新增效果只要实现同样的 build / apply 并登记进注册表，G04 / G07 / G09 / G12 / G15 都能按同一套路接。

Run locally

把 demo 跑起来

git clone https://github.com/Miracle-Shen/three-gift-effects.git
cd three-gift-effects
npm install          # 只装 three（peer dependency）
npm run demo         # → http://127.0.0.1:9100/
本地 demo 是一个不依赖任何外部素材的最小场景（地面 + 舞台 + 歌手替身 + 两张桌子）， 用来证明本库不认识任何具体场景。没装依赖时会自动回落到 unpkg CDN 上的 three。
